### 3. Обновлен компонент карты

**Файл**: `components/Map1914.tsx`

**Изменения**:
```typescript
// Было:
const countryName = NAME || name || 'Неизвестная территория';

// Стало:
const countryName = name || NAME || 'Неизвестная территория';
```

Теперь приоритет отдается переведенному полю `name`, а не английскому `NAME`.

Карта автоматически загружается при выборе года -323 в слайдере времени.
Все названия отображаются на русском языке с возможностью просмотра оригинального названия в popup.
