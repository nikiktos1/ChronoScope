# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## ChronoScope - Интерактивный исторический атлас Европы

### 1. ОПИСАНИЕ ПРОЕКТА
ChronoScope - это интерактивный веб-атлас, позволяющий пользователям визуализировать исторические изменения политических границ Европы от IX века до н.э. до 2000 года, с возможностью исследования альтернативных исторических сценариев с помощью ИИ. Приложение предназначено для широкой аудитории, желающей изучать историю в интерактивной форме.

### 2. ЦЕЛИ И ЗАДАЧИ
#### Основные цели:
- Создание интерактивного инструмента для изучения истории Европы
- Визуализация исторических изменений в реальном времени
- Предоставление возможности исследования "что если" сценариев через ИИ
- Обеспечение доступности и понятности интерфейса для всех пользователей

#### Функциональные задачи:
- Реализация интерактивной временной шкалы (тайм-слайдера)
- Создание системы карточек исторических событий
- Разработка системы "слоев" карты
- Интеграция режима "Исторический поединок"
- Внедрение ИИ-генератора альтернативной истории

### 3. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
#### 3.1 Основной интерфейс
- Интерактивная карта Европы
- Вертикальная или горизонтальная временная шкала с возможностью перетаскивания
- Панель управления слоями карты
- Поиск по странам и историческим периодам
- Система обязательной регистрации и авторизации пользователей

#### 3.2 Тайм-слайдер
- Отображение всех лет в диапазоне от IX века до н.э. до 2000 года
- Маркировка ключевых исторических событий дополнительными отметками
- Возможность ввода конкретной даты для перехода к ней
- Плавная анимация изменений границ
- Отображение исторического периода/эпохи

#### 3.3 Карточки событий
- Модальные окна с информацией о стране/империи при клике на неё
- Отображение: правителя, формы правления, столицы
- 2-3 ключевых события периода
- Возможность перехода к дополнительной информации

#### 3.4 Слои карты
- Слой политических границ
- Слой торговых маршрутов
- Слой религиозного распространения
- Слой промышленного развития
- Слой военных походов
- Слой уровня преступности (по возможности)
- Слой примерного уровня грамотности (по возможности)

#### 3.5 Режим "Исторический поединок"
- Выбор двух государств/империй из разных эпох
- Возможность выбора конкретных аспектов для сравнения (армия, экономика, технологии, территория)
- Генерация сравнительной инфографики
- Поддержка сравнения любых государств в базе с пометкой о принадлежности к Европе

#### 3.6 ИИ-составляющая
- Генератор альтернативной истории
- Интерфейс для вопросов формата "Что, если...?"
- Генерация эссе (3-4 абзаца) о возможных последствиях
- Схематическое отображение измененных границ на карте

#### 3.7 Система пользователей
- Обязательная регистрация и авторизация
- Сохранение истории просмотров
- Сохранение избранных периодов/стран
- Сохранение созданных сравнений

### 4. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
#### 4.1 Производительность
- Время загрузки карты не более 3 секунд
- Плавная анимация при изменении периодов
- Поддержка одновременной работы 50-100 пользователей
- Строгое онлайн-приложение без offline-доступности

#### 4.2 Совместимость
- Современные браузеры (Chrome, Firefox, Safari, Edge)
- Адаптивный дизайн для различных устройств
- Поддержка сенсорных экранов

#### 4.3 Безопасность
- Защита от DDoS атак
- Валидация пользовательского ввода
- Защита API от злоупотреблений
- Безопасная система аутентификации

### 5. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
#### 5.1 Фронтенд
- Next.js с TypeScript (TSX)
- Tailwind CSS для стилизации
- shadcn/ui для компонентов интерфейса
- Интерактивная карта (D3.js, Leaflet или аналоги)

#### 5.2 Бэкенд и аутентификация
- Supabase для бэкенда и аутентификации
- Хранение пользовательских данных
- API для работы с историческими данными

#### 5.3 База данных
- Хранение исторических данных
- Географические координаты границ
- Метаданные событий и персоналий
- Пользовательские данные и сохранения

#### 5.4 ИИ-компоненты
- Интеграция с openai/gpt-oss-20b API
- Кэширование результатов

#### 5.5 Внешние API
- Wikidata API
- Wikipedia API
- Europeana API (в ожидании)

#### 5.6 Хостинг и развертывание
- Vercel для хостинга
- pnpm как пакетный менеджер
